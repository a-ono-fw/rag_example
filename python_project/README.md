# 【課題2】2024年版ものづくり白書（全340ページ・31MB）を対象としたRAG型チャットボット

「2024年版ものづくり白書（令和5年度ものづくり基盤技術の振興施策）」を対象に、
1. **キーワード検索 (BM25)**
2. **ベクトル検索 (ChromaDB + text-embedding-004)**
3. **ハイブリッド検索 (BM25 + Vector RRF統合)**
の3段階検索アーキテクチャを実装した、Google Colab向けの学習用RAGチャットボットです。

---

## 💡 白書の「1節まるごとだとボリューミーすぎる」問題の解決策

白書は1つの「節」が15〜25ページ（10,000〜25,000文字）に及ぶため、1節をそのまま1チャンクにするとベクトルが希釈化し検索精度が低下します。

そこで本プロジェクトでは、**階層メタデータ保持型チャンキング**を採用しています：
- **大枠情報（第1部 第1章 第1節 見出し）**: 正規表現で自動抽出し、チャンクのメタデータとして保持
- **本文の分割**: 意味のまとまり（**600〜800文字、重複150文字**）に分割
- **回答生成**: Geminiが `[第1部 第1章 第1節 我が国ものづくり産業の現状 (p.24)]` のように章・節・ページを明確に特定して回答

---

## 🔍 3段階検索ロードマップ

| 段階 | 検索手法 | 特徴・得意領域 | ライブラリ |
| :--- | :--- | :--- | :--- |
| **ステップ1** | **キーワード検索 (BM25)** | 「価格転嫁」「サプライチェーン」等、専門用語・固有名詞の完全一致検索 | `rank-bm25` |
| **ステップ2** | **ベクトル検索 (Dense Vector)** | 「原材料高を取引価格に反映」「デジタル化の悩み」等、意味・類義語の類似検索 | `chromadb` + `gemini-embedding-001` (MRL 768次元) |
| **ステップ3** | **ハイブリッド検索 (RRF)** | BM25の順位とベクトルの順位をReciprocal Rank Fusionで融合した最高精度検索 | 独自RRF実装 (k=60) |

## 🚀 Google Colabでの実行手順

1. **Colabでノートブックを開く**:
   - `notebooks/rag_chatbot_colab.ipynb` をGoogle Colabにアップロード
2. **APIキー登録**:
   - 画面左の 🔑「シークレット」に `GEMINI_API_KEY` を登録しアクセス許可をON
3. **白書PDFの配置**:
   - `data/document.pdf`（31MB）を左パネルからドラッグ＆ドロップ、またはGitHubクローン
4. **ステップ順に実行**:
   - チャンク分割 ➔ BM25単体テスト ➔ ベクトル単体テスト ➔ ハイブリッド比較 ➔ Gradioチャット起動
